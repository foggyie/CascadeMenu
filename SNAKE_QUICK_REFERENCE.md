## 🚀 Quick Start Commands

### For AFK Farming
```
1. Enable "Auto Play"
2. Enable "Auto Restart"
3. Walk away
```

### For Instant Win
```
1. Click "Instant Win"
   (Or spam "Pellet To Snake")
```

### For Statistics
```
1. Enable "Snake Statistics"
2. Enable "Best Score Notifier"
3. Play games
```
